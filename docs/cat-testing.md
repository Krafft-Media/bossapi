# Driving & Testing

The tools that steer a boss from outside its AI, so you can exercise one attack at a time against a
chosen target and see exactly what it does.

They all act on a single **selected** boss and share the same underlying operations — the commands
are the scriptable surface, the wand and screen are the hands-on surface.

- [Selection & Manual Control](feat-selection) — the global selected boss and the mode that gates AI
  so a forced attack runs in isolation.
- [The /boss Commands](feat-commands) — the full command tree: select, goal, state, target, freeze,
  health, move, inspect, release.
- [The Boss Wand](feat-wand) — click to select a boss and to set its target in-world.
- [The Editor Screen](feat-editor) — a control panel bound to a keybind.
